The manual way

  • Hours vanish into repetitive setup: hunting references, drawing interfaces pixel by pixel, placing every element by hand.
  • One changed idea means rebuilding the whole sequence. Creative momentum dies inside the timeline.
  • Every move is a manual keyframe on every property. Calculators, calendars, counters, shop menus, all frame by frame.
  • Re-exports drift everything: codecs shift colors and blur hard voxel edges.

AgentMotion pipeline

  • The engine automates the grunt work: declarative scene in, tight PNG layers plus a manifest of tracks, positions and keyframes out.
  • Hours of hand-nudging become editing lines of text.
  • Stuck? The agent proposes layouts and variations. Variants cost nothing, so test ten ideas in the time it once took to keyframe one.
  • The output is a native Premiere timeline. Every layer, track and keyframe stays 100% editable.
  • 163 golden tests lock byte-identical rendering.

from rough idea to native timeline

Declarative scene in. Editable timeline out.

  1. STEP 1 · SCENE.JSON

    Declare layout & actions

    Claude translates natural-language prompts, scripts, or voiceover excerpts into semantic layout containers (row, column, grid, stack) and closed action primitives (show, hide, pop, slide_in, set_text, hover, cursor_move, drag, end).

  2. →
  3. STEP 2 · ENGINE

    PNG layers + manifest

    The Python engine compiles the scene into 36 clips across 19 tracks and 343 frames. Tight PNG layers with alpha, a canonical manifest.json, and a human-readable README_premiere.txt fallback.

  4. →
  5. STEP 3 · CEP PLUGIN

    One-click assembly

    The CEP plugin assembles everything in one click, in Native mode (sparse Bezier keys for hand-tweaks) or Exact mode (baked Linear keys for pixel parity). Every track, timing and keyframe stays yours, with 100% manual control to tweak afterward.

paved roads for AI · not raw motion-to-code

Built for Claude tool-use loops, vision grading, and paved-road execution.

Claude lives inside the loop, not next to it. A prompt becomes scene.json, the CLI validator answers with structured E_*/W_* feedback at exact JSON Pointer paths, and the model repairs and re-renders until the scene validates clean. Rendered previews and reference mockups feed the same vision loop, so new screens are measured, never guessed. Beyond the calculator showcase, the same loop already runs inventory screens, a torch scene, and calendar packages. It proved itself on a foreign model: first-pass 0/0/0 validation and a 74ms export on the 77-line SKILL.md. What we will not do: diffusion video that hallucinates blurry pixels, or 3D rendering inside a 2D pixel engine.

meanings, not pixels
The model picks raised panels, sunken slots, flat indicators and buttons in rows, columns and grids. The engine draws every bevel from verified Widget Cards.
zero-drift schema
Screen, scene and manifest schemas generate from the Python widget registry, so docs and engine can never drift apart.
two-tier rules
Hard E_* errors stop export with a path and a fix. Soft W_* warnings pass with allow plus reason, logged into manifest warnings.

system parameters · verified local-first build

Engineering specifications.

EnginePython + Pillow. Compiles scene.json to tight PNG layers with alpha, manifest.json, and README_premiere.txt assembly recipes.
Canvas & raster1920×1080 @60fps with alpha layers. NEAREST-only integer scaling. Pixel-art raster stays exact. 3840×2160 defined as exact ×2.
Color & verificationOriginal voxel palette. No game assets inside. 163 golden tests, byte-identical reproducibility. File + pixel hashes verified per clip.
Premiere integrationCEP / ExtendScript plus QE DOM automation, Native mode (sparse Bezier keys) plus Exact mode (baked Linear keys). Native verified 161/161 strict frames. Lossless-only MOV (qtrle/PNG). ProRes 4444 excluded after 47 color-shifted pixels from YCbCr conversion (max channel delta 2) vs. 0 differing pixels in lossless. UXP rejected after hanging silently on sequence creation.

Direction: every new screen and every hand-solved edge case expands the engine's deterministic vocabulary, for creators and AI agents alike. Lossless MOV covers what the timeline cannot.

Where the architecture goes next.

New motion & physics primitives

MCP server & reference analyzer
Validate, export and check served as a Model Context Protocol server over the CLI. An offline reference analyzer turns mockups into measured layout reports.
Event-driven audio tracks (SFX)
Actions emit frame-accurate sound events, pop to click and drop to land, into the manifest. The exporter converts your samples to .wav and the plugin lays them on native Premiere audio tracks.
Isometric 3D bridge & desktop GUI
Native block3d slot rendering and lossless MOV overlays. Then a frozen CLI contract powers an Electron studio with a visual JSON inspector.
