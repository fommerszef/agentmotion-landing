/agents

Any LLM can author scenes. Nondeterminism stops at scene.json.

An authoring agent uses our skill guide, generated JSON Schema, and self-correcting validator. Once scene.json is saved, everything below is a pure function.

  • skill guide — documents layout structure and closed action primitives (show, hide, pop, slide_in, set_text, hover, cursor_move, end).
  • JSON Schema — generated directly from the engine so schema definitions and rendering logic stay aligned.
  • self-correcting validator — every error carries an exact location and usually a fix; conscious soft-rule breaks use allow + reason and land in manifest.json.
// validator returns location + fix
{
  "level": "error",
  "path": "/timeline/action",
  "msg": "glyph not in atlas",
  "fix": {
    "op": "replace",
    "path": "/timeline/action",
    "value": "hello"
  }
}
// conscious soft-rule break lands in manifest
{
  "level": "allowed",
  "path": "/root/button",
  "reason": "explicit soft-rule override"
}

Every tested widget and action becomes a deterministic primitive reusable across future scenes.

/why

Presets give you flat clips. AgentMotion gives you an editable timeline.

Different architectures determine what lands in your NLE and whether you can keep editing after import.

preset libraries

Fixed catalog of finished flat clips.

Preset libraries sell a fixed catalog of pre-rendered clips. Once imported into your editor, the output is a flat video file with no per-layer keyframes or custom scene layouts.

generalist agent animation

Vendor-hosted generation, flat shared export.

Generalist agent animation lives on the vendor platform and ends as a flat shared file. You cannot adjust individual GUI tracks or re-time native keyframes inside Premiere Pro.

agentmotion

Editable Premiere-native timeline for any JSON scene.

Author any Minecraft-style GUI scene as declarative JSON. The engine renders voxel pixel-art layers with NEAREST-only integer scaling, and the CEP plugin builds native tracks, clips, and Position/Scale keyframes directly in Premiere Pro.
